# 小鱼工作台

原生 macOS 27 研究项目工作台，基于 SwiftUI、SwiftData 与 App Sandbox。当前实现遵循 [架构与界面规格](docs/Research_Workspace_macOS27_ARCHITECTURE_UI.md) 的外部文件夹模式：项目文件始终留在用户选择的原位置，应用只保存访问书签、项目元数据和文件索引缓存。

## 当前进度

- macOS 27、Apple silicon 原生应用工程，菜单、侧边栏、工具栏及检查器。
- 设置的“外观”页提供用户色板中的 30 个主题色，按暖色、冷色及中性色分组；默认 `#4EA3E0`，选择后即时更新控件和导航强调色。项目阶段胶囊保留各阶段颜色。
- macOS 菜单栏的自定义菜单和菜单项使用英文，与系统菜单保持一致；工作台内容仍使用中文。
- 使用小鱼插画作为应用图标。
- 一个项目可关联多个现有文件夹；每个文件夹的安全书签独立持久化，可添加、重新关联或解除关联。主文件夹及旧项目记录保留，解除附加文件夹时原文件不移动，但该文件夹在工作台的标注和投稿关联会删除。
- “全部文件”、概览、搜索、投稿文件选择器与 Jev 自动分类合并处理项目的所有关联文件夹；附加文件夹作为可浏览入口显示，同名文件以各自路径区分。嵌套或相同文件夹不允许重复关联。
- 投稿 ZIP 可从项目内多个文件夹打包；涉及附加文件夹时按来源分目录保存，避免同名文件覆盖。
- 支持多个项目间切换、重命名项目显示名称、重新关联主文件夹与从工作台移除项目。
- 侧边栏“全部项目”以整行卡片显示项目名称和上次打开时间；向下滚动按每批 20 个项目继续加载，可搜索并进入项目。卡片右侧以及当前项目概览、检查器中的彩色状态胶囊可下拉选择“筹备”至“已发表”的阶段，包括已投稿与返修；颜色取自用户提供的色板。概览和项目卡片不显示文件夹路径。
- 尚无项目时，“全部项目”空状态在内容区居中；点击空白内容区会打开现有研究文件夹选择器。
- 当前项目的“投稿期刊”可创建、编辑、删除期刊名称与网址；后台读取网页 `og:image`、`twitter:image` 和网站图标，优先展示可识别的图片，失败时显示占位封面。首次抓取结果（包括失败）会持久缓存，更换网址或手动刷新时才重新请求。
- `JEVModelClient` 接入 OpenRouter 的 TypeSafe Jev 1.13，使用 System One Decisions API 的结构化问题和回答；`WorkspaceModel.configureJEVClient(_:)` 可注入测试客户端。
- 工具栏“自动分类”按当前项目或全部项目处理文本类文件。应用在本机提取 Markdown、CSV、XLSX、Word 和常见文本文件的内容，每份文件单独请求 Jev，同时最多运行 3 个请求。单文件内容按约 29k 输入 token 的估算预算截取，保留前、中、后文；如服务端提示上下文超限会缩短并重试。图片、PDF 和无法提取正文的文件跳过；手动分类优先，模型结果单独保存，已完成的文件再次运行时跳过。分类时展示专门的进度页面，支持停止，已保存的结果会保留。
- macOS 应用菜单提供“设置”，展示图标、名称、版本、使用说明与联系邮箱；OpenRouter API Key 可保存在本机钥匙串。
- 设置中可调整侧栏透明度，并查看带时间的本地操作日志。日志记录实际变更（项目、文件、标注、期刊关联及设置），浏览、搜索、预览和刷新索引不记录。
- 每条期刊记录可关联当前项目的多个投稿文件，可通过文件选择器、文件右键菜单或把项目内文件拖到期刊行来添加；可展开查看、打开、在访达中定位及解除关联。关联记录按项目隔离并持久保存，原文件不会因关联而移动或复制；工作台内移动以及扫描发现的外部重命名会更新关联路径。
- 投稿文件选择器可直接选择任意层级的文件夹，一次关联其中各级子文件夹里的文件；右键文件夹也可关联到期刊。
- 后台递归扫描项目中的各级子文件夹，识别文件夹、软件包和符号链接；忽略常见噪音项时只对目录跳过后代，避免遗漏同级文件；缓存扫描结果。
- 科学格式识别与四维分类，支持文件夹/文件名优先规则和手动工作流覆盖。
- 项目概览、分类视图、文件表格、文件夹浏览、最近修改、收藏与元数据搜索。
- 概览随窗口宽高伸展；文件列表及概览最近修改使用 macOS 提供的文件图标。
- Quick Look、系统“打开方式”、访达定位和用默认应用打开原文件。
- 集中的文件操作服务：新建文件夹、重命名、制作副本、同项目及跨项目复制/剪切/粘贴、移到系统废纸篓、导入副本和导出副本。跨项目剪切会先复制到目标，再把来源移到系统废纸篓。复制、移动、导入遇到同名目标时，可选择保留两份、替换或停止，并可把选择应用到后续项目；项目内复制和导入先写入临时项，再移到正式文件名。
- 批量文件操作遇到错误会停止，提示已完成数量；已完成项会同步选中状态与文件索引。
- 批量文件操作显示已完成项目数，可停止后续项目；正在复制的单个大文件仍须等待系统文件操作返回。
- 可从访达拖入文件或文件夹，复制到当前目录或表格中的目标文件夹；目标区域会高亮。已接入应用内同项目拖放的默认移动和 Option 复制处理，以及向访达提供文件 URL 的拖出入口，实际拖放交互仍需端到端验证。支持复制相对路径，并可用 Return 对单个选中项发起重命名。
- 项目状态、目标期刊、说明、归档标记，以及文件收藏、标签和笔记。
- 文件收藏、标签、笔记和手动分类接入系统撤销/重做。
- 文件及文件夹可通过右键菜单置顶或取消置顶；置顶状态按项目持久保存并优先显示在文件列表顶部。
- 可把当前项目中的文件拖到侧边栏研究分类，立即保存手动分类并支持撤销；文件不会因此改变磁盘位置。
- 侧边栏废纸篓显示由小鱼工作台从当前项目移入系统废纸篓的记录，支持恢复到原路径或在访达中定位。其他应用移入系统废纸篓的文件不会出现在此列表；原文件已被系统清空时可移除失效记录。
- 使用 FSEvents 监听当前项目的递归目录变更，并在外部应用或访达修改文件后防抖刷新索引。
- 切回应用时不再无条件重扫项目，减少侧边栏重新绘制；仍可通过工具栏或菜单手动刷新。
- 文件图标按文件类型缓存，避免滚动时读取每个原文件；列表筛选、排序和侧栏分类计数按相关状态变化更新。普通文件行不再安装文件夹专用的拖放目标，降低滚动与拖动时的主线程开销。

当前仍是开发版本。文件重命名/移动的撤销、单个大文件复制中的取消、跨窗口/跨项目拖动及完整的 UI 自动化测试尚未完成。手动分类、废纸篓恢复、期刊记录持久化与文件关联已通过临时项目单元测试；自动化工具未能可靠触发 macOS 的拖动手势，因此侧栏及期刊行拖放仍需真实鼠标验证。封面识别取决于期刊网站提供的公开图片元数据和网络可用性，无法保证每个链接都能得到期刊封面。文件操作请先在测试项目中试用；正式分发前仍需签名沙盒环境下的端到端验证。

## 构建与测试

需要 Xcode 27 和 XcodeGen：

```sh
xcodegen generate
xcodebuild -project XiaoYuWorkspace.xcodeproj -scheme XiaoYuWorkspace \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO test
```

本地单元测试构建使用 `CODE_SIGNING_ALLOWED=NO`。可用 Apple Development 证书构建本机签名版本；对外分发仍需合适的分发证书与验证。`XiaoYuWorkspace.entitlements` 中保留 App Sandbox、用户选取文件读写授权和用于识别期刊封面的网络访问授权。

默认测试方案只运行单元测试。`XiaoYuWorkspaceUITests` 仍保留供配置正式签名后运行，避免本机无签名的 UI 测试运行器提前退出影响默认测试。

应用 Bundle ID：`com.xiaoyu.workspace.native27`。此 ID 与旧版隔离，避免读取旧版的沙盒数据库。

侧边栏使用 Alex Martynov 的 Unoline 图标。该图标集允许在个人及商业项目中使用和修改，原始图标包不得未经许可重新分发。
